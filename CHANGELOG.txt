================================================================================
 iSealTwist - Changelog
================================================================================

v0.6.3 - Release
--------------------------------------------------------------------------------

 [CHANGED] Added Classic Era interface 11509 while retaining TBC interfaces
           20505 and 20506
 [NEW] A chat confirmation now shows the selected seal pair after the managed
       SealTwist macro is successfully updated
 [CHANGED] The seal-pair selector now hides Horde-only seals for Alliance and
           Alliance-only seals for Horde, repairing incompatible saved choices
           with their faction equivalents
 [CHANGED] Twist success and failure text now appears in a dedicated row above
           the swing bar instead of covering the timer content
 [FIX] Twist feedback now detects seal changes from successful casts when aura
       events arrive without a usable spell ID or in an unexpected order
 [FIX] The managed SealTwist macro now recognizes older generated formats and
       updates when either configured seal is changed; combat-locked updates
       are applied after combat
 [CHANGED] Alert border is thicker and displays a stronger red pulse when an
           active GCD makes it too late to twist before the next swing

v0.6.1 - Release
--------------------------------------------------------------------------------

 [NEW] Customization tab with native WoW color pickers and a Default Colors button
 [NEW] Adjustable seal icon, current-seal text, latency text, and twist-result text sizes
 [NEW] Selectable in-game fonts for all swing-timer text
 [NEW] Sound Effects tab with short built-in WoW sounds for successful twists,
       failed twists, and wrong-seal warnings near the next swing
 [NEW] Optional iSoundPlayer integration exposes registered custom sounds in iST
 [CHANGED] Swing timer has a rounder modern bar, circular seal icon, and redesigned
           wrong-seal alert border
 [CHANGED] Settings are reorganized into General, Timing, Indicators,
           Customization, Sound Effects, and About tabs
 [CHANGED] Sound Effects tab includes a Work in Progress notice
 [CHANGED] Removed deprecated iCommunityChat from the Other Addons panel

v0.5.1 - Release
--------------------------------------------------------------------------------

 [FIX] Added Holy Light rank 11 (spell ID 27136) to swing-reset detection
 [FIX] Twist success/failure feedback now only evaluates the configured
       FROM-to-INTO seal transition
 [FIX] Wrong Seal Warning now activates when neither configured seal is active
 [FIX] GCD tracking now reads the real global cooldown, avoiding false GCDs from
       off-GCD abilities and adapting the marker to the observed GCD duration
 [FIX] Live option changes now refresh idle bar dimensions, colors, and latency
       visibility immediately
 [FIX] Auto-created SealTwist macros now follow the configured seal pair, use
       localized spell names, and safely migrate untouched older macros
 [FIX] Unsupported-client warning no longer incorrectly claims features are
       disabled
 [FIX] Release packaging now validates the tag against the TOC and publishes the
       matching changelog section through the supported BigWigs configuration

v0.4.2 - Release
--------------------------------------------------------------------------------

 [FIX] Retribution specialization detection now supports both the older Classic
       and TBC Anniversary talent API return layouts, preventing the 0.4.1 crash
 [FIX] Swing-reset spells now reset the timer on SPELL_CAST_SUCCESS, including
       Holy Light, Flash of Light, Hammer of Justice, and Repentance
 [FIX] Enabling the addon from the minimap updates bar visibility immediately
 [FIX] "Only Active as Paladin" now takes effect immediately when changed
 [FIX] Installed sister addons are detected through the legacy IsAddOnLoaded()
       API when C_AddOns is unavailable
 [CHANGED] Idle/stale bar appearance is applied once per state transition instead
           of recalculating visibility on every frame

v0.3.1 - Release
--------------------------------------------------------------------------------

 [FIX] Bar invisible when "Only Show In Combat" is unchecked — idle state now
       shows a faint full-width bar so the frame is always clearly visible
 [FIX] Test bar auto-stop (30s) now respects the "Only Show In Combat" setting;
       bar stays visible after test ends if the setting is off
 [FIX] Active seal not detected on login — initial scan now runs after the
       player is fully in the world, where buff data is accessible

v0.3.0 - Release
--------------------------------------------------------------------------------

 [NEW] Swing timer now resets on cast-interrupt spells (Found by: IvanRL22)
       Detects all ranks of: Repentance, Holy Wrath, Hammer of Justice,
       Hammer of Wrath, Holy Light, Flash of Light
 [FIX] Crusader Strike no longer resets the swing timer bar — CS is a special
       attack in TBC and does not affect the auto-attack swing timing

v0.2.5 - Release
--------------------------------------------------------------------------------

 [NEW] "Only Active In Retribution Spec" setting — bar automatically hides when
       you are in Holy or Protection spec; detected by talent tree point count
 [FIX] "Only Show In Combat" unchecked now correctly shows bar outside combat as
       an idle (empty) bar; toggling the setting takes effect immediately
 [CHANGED] All show/hide decisions route through a single UpdateBarVisibility()
           function — spec, combat, and enabled checks are always consistent

v0.2.4 - Release
--------------------------------------------------------------------------------

 [NEW] Pulse Indicators — three color-coded bar pulses for seal twist state:
  - Green  : Seal1 active + inside twist window + GCD free → cast Seal2 now
  - Orange : Seal2 active → twist completed, waiting for swing
  - Red    : Seal1 active + active GCD will not expire before swing → too late
 [NEW] Each pulse can be toggled independently in Display → Pulse Indicators

v0.2.3 - Release
--------------------------------------------------------------------------------

 [NEW] GCD Indicator — gold marker line one GCD (1.5s) before the twist window
 [NEW] GCD Zone — gray shaded block on the bar showing the active GCD window
       (tracks real spell casts via UNIT_SPELLCAST events)
 [NEW] Wrong Seal Warning — fill + border turn red when past the GCD mark and
       not on either configured twist seal; also fires inside the twist window
 [NEW] Seal Pair settings in Display tab
  - "Seal to Twist" dropdown: Seal of Command or Seal of Righteousness
  - "Seal to Twist Into" dropdown: any seal (defaults faction-aware:
    Seal of Blood for Horde / Seal of the Martyr for Alliance)
 [NEW] Bar Colors section in General tab — RGBA sliders for every bar color:
  - Fill, Twist Zone Fill, Alert, GCD Zone, Twist Marker, GCD Marker, Border
 [NEW] Twist text size slider in Display tab (8–32pt)
 [CHANGED] Twist result text now uses configurable size (default 16pt)

v0.1.0 - Release
--------------------------------------------------------------------------------

 [NEW] Visual Swing Timer Bar
  - Standalone movable/lockable bar tracking white melee swing timer
  - Fills left-to-right with time remaining countdown
  - Weapon speed display on the bar
  - Auto-hides out of combat (configurable)

 [NEW] Twist Window Indicator
  - Vertical marker line showing ideal twist point on the bar
  - Colored zone (green) from twist point to end of swing
  - Configurable twist window (200-600ms, default 400ms)
  - Latency compensation: adjusts twist point based on home latency

 [NEW] Seal Tracking
  - Displays active seal icon next to the bar
  - Seal name shown below the bar
  - Detects all TBC seals (Command, Blood, Righteousness, Vengeance, etc.)
  - Updates on seal change via combat log and aura scanning

 [NEW] Settings Panel (/ist settings)
  - Bar dimensions (width/height sliders)
  - Twist window timing slider
  - Latency display toggle
  - Seal icon toggle
  - Combat-only and Paladin-only options
  - Lock/unlock bar position
  - Reset position and test mode buttons

 [NEW] Slash Commands
  - /ist settings — Open settings panel
  - /ist lock — Toggle bar lock
  - /ist reset — Reset bar position to center
  - /ist test — Simulate a 3.6s swing for testing
