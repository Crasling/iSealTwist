# iSealTwist

iSealTwist is a Paladin weapon swing timer for World of Warcraft: Forever. It also shows Echo stacks and optional Seal switching cues when you learn Unsealed Wrath.

## Getting started

Right-click the iSealTwist minimap icon to open settings, or left-click it for the Seal Pair and Macro panel. Search for a setting from the top of the window, or open **Profiles → Starter Profiles** to try a ready-made display.

In **General → Activation**, use **Enable iSealTwist** to turn the addon on or off. Under **Swing Bar**, turn off **Show Swing Bar** to keep the Seal icon and Echo indicators without the bar.

Use **Edit Layout** to move your enabled indicators and reminders. Open **Switch & Attack** to change or turn off the center messages. **Reminders** and **Sounds** have separate tabs for each buff.

## Chat commands

| Command | Action |
| --- | --- |
| /ist | List commands |
| /ist settings | Open or close settings |
| /ist new or /ist news | Open What's New |
| /ist edit | Start or finish editing the layout |
| /ist lock | Toggle the position lock |
| /ist reset | Reset the swing bar position |
| /ist test | Test the swing bar |
